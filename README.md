# Interfacing-an-LDR-to-detect-light-intensity-and-display-voltage-changes using Arduino UNO
Exp 2 Interfacing an LDR with Arduino UNO to Detect Light Intensity 
Aim
To interface an LDR with Arduino UNO and control an LED to turn ON and OFF according to the detected light intensity.
Components Required
•	Arduino UNO 
•	LDR 
•	10 kΩ resistor 
•	Breadboard 
•	Connecting wires 
•	USB cable 
•	Computer with Arduino IDE 
Circuit Diagram
 



Procedure
1.	Connect the LDR and 10 kΩ resistor as a voltage divider on the breadboard. 
2.	Connect the junction of the LDR and resistor to A0 of Arduino UNO. 
3.	Connect the circuit to the Arduino UNO and upload the program using Arduino IDE. 
4.	Open the Serial Monitor at 9600 baud. 
5.	Expose the LDR to different light conditions and note the corresponding voltage.

Result
The LDR-based automatic light control system was successfully implemented using Arduino UNO. The LED was programmed to turn ON in low-light/dark conditions and turn OFF in bright-light conditions.
